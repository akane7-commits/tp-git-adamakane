# Calculatrice Java - TP Git & GitHub

## Présentation

Ce projet est une petite calculatrice développée en Java dans le cadre du TP Git et GitHub.

L'objectif est de pratiquer les commandes Git et d'apprendre à gérer un projet avec GitHub.

## Fonctionnalités

- Addition
- Soustraction
- Multiplication
- Division
- Puissance
- Modulo

## Installation et exécution

Pour compiler le programme :

javac Main.java

Pour exécuter le programme :

java Main

## Technologies utilisées

- Java
- Git
- GitHub
